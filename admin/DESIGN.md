# 后台页面的设计方向

改后台页面之前先读这一页。新页面照这里做，要偏离就先改这一页，写清楚为什么。

## 读法

只给运营者一个人用的学校后台，信息密、安静，Ant Design 打底。

调子：ENERGY 1 / RHYTHM 1 / MOTION 1。

- ENERGY 1：页面不招呼人，打开就是数字和要做的事。
- RHYTHM 1：面板一个样，图表两列等宽，整齐是有意的：每天来看的人要一眼找到同一个位置。
- MOTION 1：没有动效（`motion: false`，按钮点击也没有水波纹），只有悬停、按下和焦点的样子。加载时不转圈，写字说明正在读什么。

## 只做电脑版

最小宽度 1200px，窄于这个宽度时页面横向滚动。后台只有一个人在电脑上用，所以不做手机适配（做页面时遵守的 anti-slop 规则里，这一条按使用者的决定放宽，手机布局那部分规则没有加载）。其余规则照常：三种状态、键盘、焦点、对比度、文字。

## 颜色

| 用途 | 颜色 | 说明 |
|---|---|---|
| 主色（黑板绿） | `#2f5d50` | 顶部的条、主要按钮、选中的标签、焦点框。上面放白字，对比度 7.49:1 |
| 红笔 | `#c8312b` | 只用于审核标记（像老师批改的红笔），以及学校数据页上唯一的警报：本月花费超预算。白底上 5.34:1 |
| 页面底色 | `#f7f6f2` | 纸的颜色 |
| 面板 | `#ffffff`，边框 `#e3e2dc` | 不加阴影；唯一的阴影在图表的读数框上，因为它浮在图上 |
| 不能用的按钮上的字 | `#66655e` | 按钮在发送时只靠这几个字说明进度（正在登录、正在删除），所以要读得清：灰底上 5.37:1，纸色底上 4.95:1，白底上（不能点的链接按钮）5.85:1。灰底和"不能点"的光标仍然说明它现在用不了（Ant Design 默认的只有 1.82:1） |
| 输入框、按钮的边 | `#8a8980` | 白底上 3.52:1，页面底色上 3.25:1，看得出控件在哪（Ant Design 默认的 `#d9d9d9` 只有 1.41:1）。分隔线仍用浅的 `#e3e2dc` |
| 正文 | `#1f1f1f` | 页面底色上 15.24:1 |
| 次要文字 | `#4a4a4a`、`#5c5c5c` | `#5c5c5c` 在页面底色上 6.18:1，白底上更高 |
| 输入框提示文字 | `#767676` | 白底上 4.54:1 |

其余一律中性色。表单没填的提示用深灰加文字，不用红色（`theme.ts` 里给 Form 和 Input 单独改了 `colorError`），因为红色留给红笔。

图表的线用 dataviz 参考调色板，按这个顺序取色，主色和红笔色都不画线：

`#2a78d6`、`#eb6834`、`#1baf7a`、`#eda100`、`#e87ba4`、`#008300`、`#6250d6`

三条线的图取前三个，花费按七种用途取前七个。其中几种浅色在白底上不到 3:1，所以多条线的图都有图例、线尾标名字，还能切换成表格看。

只做浅色。红笔批改的样子是白纸上的红字，深色底会把这个意思弄丢；以后要加深色，两套都得能用。

## 字体

系统自带的中文字体：`"PingFang SC","Microsoft YaHei","Noto Sans CJK SC",system-ui,sans-serif`。不加载网络字体。正文 14px；昨天的数字 26px，是每一屏唯一最醒目的东西。

唯一的例外是红笔批注：用系统自带的楷体（`"Kaiti SC",STKaiti,KaiTi,"AR PL UKai CN"`，没有就退回上面那组），像老师在页边手写的字，和印出来的课文分得开。审课页的课文 15px，行距 1.9，读长段落不累。

## 学校自己的特色：红笔批改

审课页上，有问题的字句下面画红色波浪线，页边写红字批注，像老师改作业。红色因此只给这件事，别处一用，红笔就不显眼了。

审课页的样子（`src/pages/Review.tsx`）：

- 左边是这几天的课，每天三个学部，状态用字写（已通过、红笔 N 处、待审、待生成、生成失败、已开课、当天已定）；还要做事的课位字深一些、粗一些。选中的课位底色浅绿，左边一道主色的边，不只靠颜色区分。
- 右边一节课像一本改过的作业本：左边是课文，右边是有细线隔开的页边。每一处（标题、每段正文和要点、两道点名题）都有自己的页边；没有标记的写灰字"没有批注"，不留空白。
- 被拒绝的改动，原因写在动手的地方，用细框框起来，不用红色。
- "通过，审下一节"贴在窗口底部，读到哪里都点得到。

## 每周复盘、查学生、开关

这三页是"查和改"的页面，照学校数据页的样子：纸色底上的白面板，没有装饰卡片。

- 数字放在表格里：表名写在表格上面（`caption`），行之间细线，数字靠右、等宽。一张表回答一件事（"点名，按学部"），不做成一排排大数字。
- 每周复盘按设计的六块排：上课、课程、老师、审核、学生、花费，最后是"已删的词和已停用的规则"，方便照着改词库文件。最上面选哪一周（原生 `select`，键盘直接用）。
- 大模型的两项（修改方向、建议停用的词）分清三种情况，各说各的话：还没复盘、这一项没生成出来（写出原因）、生成了但没有建议。整周什么都没有时，不摆六块零，直接说这一周没上课也没花钱。
- 查学生：带标签的学号输入框，结果分资料、消息记录、违纪记录三块；消息一次读一页，往下点"再读更早的消息"。
- 开关：一行一个，开着和关着的效果都写出来，现在生效的那句字深，另一句灰；写最近一次切换的时间。

改了就收不回来的操作（删词、停用规则、手动停课、退学、解除处罚、切换开关）都先弹一个确认框（`components/Confirm.tsx`）：标题问要不要做，正文一句一句写后果，按钮写清做什么（"删掉这个词""办退学""关掉"），另一个按钮写"先不删""先不办"。焦点先落在退一步的那个按钮上，后果是它的说明，读屏会一起读出来。服务器拒绝时，原因写在框里并拿到焦点；做完了，框关掉，结果写在动手的地方并拿到焦点。

## 时间

页面上的时间都按学校的时区显示，不按这台电脑的时钟：登录和查登录状态时，服务器把时区一起给页面（`src/zone.ts`）；学校数据页用它自己那份数据里的时区；"今天"用审课列表给的学校日期。所以在别的时区打开后台，开门时间、切换开关的那一天、能指定题目的日子都不会错。

## 写字

- 页面上的字用中文，按钮写它做的事（去审课、重新读取、用表格看），不写"确定""提交"这类空话。
- 不用破折号，不在按钮和标题上放装饰用的箭头、图标或表情符号。
- 空、加载中、出错都写清原因和下一步：
  - 空："最近 7 天还没有数据。学校开学后，第二天这里会出现第一组数字。"
  - 加载中："正在读取学校数据"
  - 出错："没能读取学校数据。连不上服务器，检查网络后再试。" 加一个"重新读取"。
- 服务器给的中文原因原样显示（409、422、503 都是这样），不另编。
- 页面上的数字都来自接口；没有数字就不显示数字。

## 键盘和焦点

每个能点的东西都能用 Tab 走到，Enter 或空格能用。焦点框是 3px 的主色（Ant Design 控件）或 2px（页面自己的元素），在绿色顶部条上是白色。不要去掉焦点框。图表本身也能聚焦：左右方向键逐天看数字，Home、End 到头尾，Esc 收起。

确认框：打开时焦点在"先不……"那个按钮上，Tab 在框里转，Esc 关掉，焦点回到打开它的按钮；做完以后焦点到写结果的那一句。

审课页：课的列表在 Tab 顺序里只占一站（选中的那一课），上下键换课，Home、End 到头尾。Esc 关掉对话框，也收起改字和写理由的框，焦点回到打开它的按钮（对话框关掉也一样）。点了按钮以后按钮会暂时不能用，焦点就交给接下来出现的东西：被拒绝的原因、要确认的话、通过以后下一节课的标题、点了"这是误伤"以后下一处"这是误伤"（没有了就是"通过，审下一节"），以及改到一半这节课开课时的那句说明。

一节课同时只改一处：一个改动没回来以前（重写可能要一分钟以上），别的改动按钮和打开框的按钮都暂时不能用，等着结果的框也不会被别的框挤掉。

## 图表

图表用 `src/components/LineChart.tsx` 自己画的 SVG，没有用 Ant Design Charts：它画在 canvas 上，键盘走不到，jsdom 里也测不了，而且包很大。这里要的样子它都要自己再配一遍：

- 标题写成图回答的问题，比如"每天有多少学生来上课？"；
- 线 2px，网格线是细的实线；
- 多条线的图有图例，线尾再标一次名字，名字挤在一起时用引线错开；
- 鼠标悬停或键盘聚焦时，显示那一天每条线的数字；
- 切换过运行时开关的日子画一条竖线，读数里写出几点切换了哪个开关；
- 每张图都能切换成表格看（最新的一天在最上面）。

切换 7、30、90 天时，旧图留着、线先变淡（字不变淡，对比度不降），上面一行字说正在读哪几天，新数据到了再换，不闪空白。

## 本地开发

`npm run admin:dev` 在 http://localhost:5173/ 打开页面，把 `/api/...` 转给本机的报名服务。用到的环境变量从仓库根目录的 `.env` 或命令行读：

- `ADMIN_PATH`：和报名服务用的是同一个变量。不设就不转发。
- `ADMIN_DEV_SERVER`：报名服务的地址，不设就是 `http://localhost:{REGISTRATION_PORT}`（默认 8080）。

报名服务给的登录 Cookie 带 Secure，本地开发用 Chrome 或 Firefox（它们把 localhost 当成安全来源）。

打包后的页面里所有地址都是相对的（`base: './'`，请求写成 `api/...`），后台路径只在服务器的环境变量里，不进仓库、不进打包结果。
