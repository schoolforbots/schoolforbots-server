# 后台页面的设计方向

改后台页面之前先读这一页。新页面照这里做，要偏离就先改这一页，写清楚为什么。

## 读法

学校的后台给运营学校的人（运营者）用，只有一个账号。页面信息密、安静。

样子照 [HyperUI](https://hyperui.dev/) 的应用组件（application components）和它的分析看板模板（analytics dashboard）：左边一条白色侧栏放各页，右边上方一条白色的页头写这一页叫什么、做什么，下面是浅灰底上的白卡片。用 Tailwind CSS（v4，`@tailwindcss/vite`）写，不用组件库。按钮、输入框、单选、确认框这几样控件在 `src/ui.tsx`，都是原生的 HTML 元素，键盘、读屏和测试看到的就是按钮、输入框、单选和对话框。

2026-11 以前用 Ant Design 打底。换掉的原因：样子和 HyperUI 的看板对不上，每个颜色、边框、焦点框都要在主题里一项项改回来（对比度不够）；包也大（约 300 kB gzip，换掉以后整个页面约 100 kB）。

调子：ENERGY 1 / RHYTHM 1 / MOTION 1。

- ENERGY 1：页面不招呼人，打开就是数字和要做的事。
- RHYTHM 1：卡片一个样，图表两列等宽，整齐是有意的：每天来看的人要一眼找到同一个位置。
- MOTION 1：没有动效，只有悬停、按下和焦点的样子（按钮的底色在悬停时换一下）。加载时不转圈，写字说明正在读什么。

## 只做电脑版

最小宽度 1200px，窄于这个宽度时页面横向滚动。后台按在电脑上使用来设计，不做手机适配。其余要求照常，见下面各节：颜色的对比度，写字（包括空、加载中、出错三种状态），键盘和焦点。

## 页面的框架

- 侧栏 240px 宽，白底，右边一道细线，跟着窗口不动。最上面是校名（一个绿底白字的“校”和“机器人网校 / 后台”两行），下面一页一行，最下面是“退出登录”。
- 侧栏里的每一页是链接（`#data`、`#review`……），当前这一页 `aria-current="page"`：浅绿底、绿字、左边一道主色的边，不只靠颜色区分。“审课”旁边用小圆角的灰底标签写待审几节（读不到就写“待审数没读到”）。
- 页头白底，下面一道细线：`h1` 是这一页的名字，下面一句灰字说这一页做什么。整页只有这一个 `h1`；页面内容放在以它为名的 `main` 里。浏览器标签页的标题跟着换（“审课 · 机器人网校后台”）。
- 卡片：白底，1px 的 `gray-200` 边，8px 圆角，一层很淡的阴影（`shadow-xs`）。
- 登录页：浅灰底中间一张卡片，上面是校名。

## 颜色

颜色写在 `src/styles.css` 的 `@theme` 里，`src/palette.test.tsx` 从那里读出来检查下面的对比度。灰色用 Tailwind 的一组（写成 hex，测试才算得准），只有 `gray-500` 比 Tailwind 的深一点。

| 用途 | 颜色 | 说明 |
|---|---|---|
| 主色（黑板绿）`brand` | `#2f5d50` | 主要按钮、侧栏里当前的那一页、选中的选项、焦点框。上面放白字，对比度 7.49:1；悬停 `#245146` |
| 浅绿 `brand-tint` | `#e8efec` | 当前那一页和选中的课位、选项的底色。上面的绿字 6.42:1 |
| 红笔 `red-pen` | `#c8312b` | 只用于审核标记（像老师批改的红笔），以及学校数据页上唯一的警报：本月花费超预算。白底上 5.34:1 |
| 页面底色 | `gray-50` `#f9fafb` | |
| 卡片 | 白，边框 `gray-200` `#e5e7eb` | 一层很淡的阴影；图表的读数框和对话框的阴影重一些，因为它们浮在上面 |
| 不能用的按钮上的字 `disabled` | `#4b5563` | 按钮在发送时只靠这几个字说明进度（正在登录、正在删除），所以要读得清：灰底（`gray-100`）上 7.0:1 以上。灰底和“不能点”的光标仍然说明它现在用不了 |
| 输入框、按钮的边 `edge` | `#868d97` | 白底上 3.2:1，页面底色上 3.2:1，看得出控件在哪（Tailwind 常用的 `gray-300` 只有 1.5:1）。分隔线仍用浅的 `gray-200` |
| 正文 | `gray-900` `#111827` | |
| 次要文字 | `gray-600` `#4b5563`、`gray-500` `#636a75` | `gray-500` 在灰底（`gray-100`）上也有 4.5:1 |
| 输入框提示文字 `placeholder` | `#6b7280` | 白底上 4.83:1 |

其余一律中性色。表单没填的提示用深灰加文字，不用红色，因为红色留给红笔。和上周比多了少了也一样：写在灰底的小标签里，不用绿色和红色。

图表的线按这个顺序取色，主色和红笔色都不用来画线：

`#2a78d6`、`#eb6834`、`#1baf7a`、`#eda100`、`#e87ba4`、`#008300`、`#6250d6`

三条线的图取前三个，花费按七种用途取前七个。其中几种浅色在白底上不到 3:1，所以多条线的图都有图例、线尾标名字，还能切换成表格看。

只做浅色。红笔批改的样子是白纸上的红字，深色底会把这个意思弄丢；以后要加深色，两套都得能用。

## 字体

系统自带的中文字体：`"PingFang SC","Microsoft YaHei","Noto Sans CJK SC",system-ui,sans-serif`。不加载网络字体。正文 14px；今天和昨天的数字 28px，是每一屏最醒目的东西。

唯一的例外是红笔批注：用系统自带的楷体（`"Kaiti SC",STKaiti,KaiTi,"AR PL UKai CN"`，没有就退回上面那组），像老师在页边手写的字，和印出来的课文分得开。审课页的课文 15px，行距 1.9，读长段落不累。

## 学校自己的特色：红笔批改

审课页上，有问题的字句下面画红色波浪线，页边写红字批注，像老师改作业。红色因此只给这件事，别处一用，红笔就不显眼了。

审课页的样子（`src/pages/Review.tsx`）：

- 左边是这几天的课，每天三个学部，状态用字写（已通过、红笔 N 处、待审、待生成、生成失败、已开课、当天已定）；还要做事的课位字深一些、粗一些。选中的课位底色浅绿，左边一道主色的边，不只靠颜色区分。
- 右边一节课像一本改过的作业本：左边是课文，右边是有细线隔开的页边。每一处（标题、每段正文和要点、两道点名题）都有自己的页边；没有标记的写灰字"没有批注"，不留空白。
- 被拒绝的改动，原因写在动手的地方，用细框框起来，不用红色。
- "通过，审下一节"贴在窗口底部，读到哪里都点得到。

## 学校数据页的今天和昨天

最上面是今天，下面是昨天，再下面是提醒和曲线。两栏的样子一样：八个数字排成两行、每行四个的统计卡片（HyperUI 的 stats），卡片之间一道细线；每个数字下面用灰底小标签写和上周同一天比多了还是少了。

- 今天的标题写"今天（截至 16:00）"：数字从学校时区的零点算到读取的那一刻，一节课下了课，它的数据就都在里面。比较也只截到同一时刻，不拿半天和一整天比。标题下面写一次"和上周三零点到 16:00 的数字比。"，每个数字下面照昨天的写法（"比上周三多 4"），格子窄，长的话会折成两行。
- 今天的数字一直在涨，标题旁边的"更新到现在"重新读一遍。读的时候按钮写"正在更新"，不变成不能点（那样焦点会丢），再点一次不会多读一遍。
- 今天不上课（还没开学、放假、不上自习的周末、维护中）时，标题下面用一句话说为什么，数字照样显示：报名和大模型花费不停。
- 本月花费和预算写在今天的花费下面，本月的数里已经有今天的。
- 昨天和上周同一天的一整天比。
- 曲线只画到昨天：今天还没过完，画进去会像突然跌了一截。

## 每周复盘、查学生、开关

这三页是"查和改"的页面，照学校数据页的样子：浅灰底上的白卡片，不加装饰。

- 数字放在表格里：表名写在表格上面（`caption`），行之间细线，数字靠右、等宽。一张表回答一件事（"点名，按学部"），不做成一排排大数字。
- 每周复盘分六块：上课、课程、老师、审核、学生、花费，最后是"已删的词和已停用的规则"，方便照着改词库文件。最上面选哪一周（原生 `select`，键盘直接用）。
- 大模型的两项（修改方向、建议停用的词）分清三种情况，各说各的话：还没复盘、这一项没生成出来（写出原因）、生成了但没有建议。整周什么都没有时，不摆六块零，直接说这一周没上课也没花钱。
- 查学生：带标签的学号输入框，结果分资料、消息记录、违纪记录三块；消息一次读一页，往下点"再读更早的消息"。
- 开关：一行一个，名字旁边一个小标签写现在开着（浅绿）还是关着（灰）；开着和关着的效果都写出来，现在生效的那句字深，另一句灰；写最近一次切换的时间。

改了就收不回来的操作（删词、停用规则、手动停课、退学、解除处罚、切换开关）都先弹一个确认框（`components/Confirm.tsx`）：标题问要不要做，正文一句一句写后果，按钮写清做什么（"删掉这个词""办退学""关掉"），另一个按钮写"先不删""先不办"。焦点先落在退一步的那个按钮上，后果是它的说明，读屏会一起读出来。服务器拒绝时，原因写在框里并拿到焦点；做完了，框关掉，结果写在动手的地方并拿到焦点。

## 时间

页面上的时间都按学校的时区显示，不按这台电脑的时钟：登录和查登录状态时，服务器把时区一起给页面（`src/zone.ts`）；学校数据页用它自己那份数据里的时区；"今天"用审课列表给的学校日期。所以在别的时区打开后台，开门时间、切换开关的那一天、能指定题目的日子都不会错。

## 写字

- 页面上的字用中文，按钮写它做的事（去审课、重新读取、用表格看），不写"确定""提交"这类空话。
- 不用破折号，不在按钮和标题上放装饰用的箭头、图标或表情符号。
- 空、加载中、出错都写清原因和下一步：
  - 空："最近 7 天还没有数据。学校开学后，第二天这里会出现第一组数字。"
  - 加载中："正在读取学校数据"
  - 出错："没能读取学校数据。连不上服务器，检查网络后再试。" 加一个"重新读取"。
- 服务器给的中文原因原样显示（409、422、503 都是这样），不另编。
- 页面上的数字都来自接口；没有数字就不显示数字。

## 键盘和焦点

每个能点的东西都能用 Tab 走到，Enter 或空格能用。焦点框是 2px 的主色；输入框聚焦时边框也变成主色。不要去掉焦点框。图表本身也能聚焦：左右方向键逐天看数字，Home、End 到头尾，Esc 收起。

确认框：打开时焦点在"先不……"那个按钮上，Tab 在框里转，Esc 关掉，焦点回到打开它的按钮；做完以后焦点到写结果的那一句。

审课页：课的列表在 Tab 顺序里只占一站（选中的那一课），上下键换课，Home、End 到头尾。Esc 关掉对话框，也收起改字和写理由的框，焦点回到打开它的按钮（对话框关掉也一样）。点了按钮以后按钮会暂时不能用，焦点就交给接下来出现的东西：被拒绝的原因、要确认的话、通过以后下一节课的标题、点了"这是误伤"以后下一处"这是误伤"（没有了就是"通过，审下一节"），以及改到一半这节课开课时的那句说明。

一节课同时只改一处：一个改动没回来以前（重写可能要一分钟以上），别的改动按钮和打开框的按钮都暂时不能用，等着结果的框也不会被别的框挤掉。

## 图表

图表用 `src/components/LineChart.tsx` 自己画的 SVG，没有用图表库：画在 canvas 上的键盘走不到，jsdom 里也测不了，而且包很大。这里要的样子它都要自己再配一遍：

- 标题写成图回答的问题，比如"每天有多少学生来上课？"；
- 线 2px，网格线是细的实线；
- 多条线的图有图例，线尾再标一次名字，名字挤在一起时用引线错开；
- 鼠标悬停或键盘聚焦时，显示那一天每条线的数字；
- 切换过运行时开关的日子画一条竖线，读数里写出几点切换了哪个开关；
- 每张图都能切换成表格看（最新的一天在最上面）。

切换 7、30、90 天时，旧图留着、线先变淡（字不变淡，对比度不降），上面一行字说正在读哪几天，新数据到了再换，不闪空白。

## 本地开发

`npm run admin:dev` 在 http://localhost:5173/ 打开页面，把 `/api/...` 转给本机的报名服务。用到的环境变量从仓库根目录的 `.env` 或命令行读：

- `ADMIN_PATH`：和报名服务用的是同一个变量。不设就不转发。
- `ADMIN_DEV_SERVER`：报名服务的地址，不设就是 `http://localhost:{REGISTRATION_PORT}`（默认 8080）。

报名服务给的登录 Cookie 带 Secure，本地开发用 Chrome 或 Firefox（它们把 localhost 当成安全来源）。

打包后的页面里所有地址都是相对的（`base: './'`，请求写成 `api/...`），后台路径只在服务器的环境变量里，不进仓库、不进打包结果。
